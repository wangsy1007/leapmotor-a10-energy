# 零跑 A10 电耗

给 **零跑 A10 505 激光雷达版** 用的 Android 分段里程电耗统计。手机端运行，不装在车机上。面向黑龙江大庆这种冬季极寒场景：记录每一段实际里程、掉电、百公里电耗，以及电池最低温和车内温度。

标称 CLTC 505 km，电池约 53 kWh 磷酸铁锂。应用里的可用容量默认 **50.0 kWh**，可以按一次真实充电改掉。这台车没有热泵，冬天暖风会明显抬高空调电耗。

协议是国内零跑非官方云端接口，整理在 [docs/PROTOCOL.md](docs/PROTOCOL.md)。公开资料的实测车型是 C10 等，**没有 A10**。本应用把 A10 当成同一套登录和能耗接口的未验证车型：车况会先走默认网关，拿不到 `signalMap` 再按 `getCarRoute.appRegion` 试 form 和 JSON。第一次使用请打开诊断页核对原始字段。

## 能做什么

- 共享子账号短信登录。`deviceId` 固定保存。账号 token 用 `getnewtoken` 续期，车端 JWT 到期前重新交换。令牌放在加密存储里。
- 前台服务轮询车况。默认行驶中 6 秒、停车 60 秒。命中 1023 会指数退避并停手。
- 按档位、车速、里程和停车超时自动切段。充电或插枪会结束当前段，并且不把充电过程记成行程。
- 每段保存起止时间、ΔODO、ΔSOC、kWh、kWh/100km、起止 SOC、电池最低温、车内温度，以及 SOC 来自精确值还是整数。
- 可以手动开始 / 结束、补录、改备注和标签、删除、导出 CSV。
- 统计今日、本周、本月、全部的里程、耗电和加权百公里电耗，并按电池温度分档。
- 同步官方 `getLastweekEC` 的驱动 / 空调 / 其他，以及按日里程。不用 `accumulatedEnergyConsume`。
- 诊断页可以查看并脱敏复制车辆列表、路由、原始 `signalMap` 和能耗 JSON。

云端没有逐条历史行程。官方 App 也不再提供里程详情。分段只能靠轮询本地计算。

## 务必使用共享子账号

零跑云是单账号单会话。用主账号登录会把手机上的官方 App 顶下线。

1. 在官方 App 里把车辆共享给另一个手机号。
2. 子账号接受共享。
3. 只用这个子账号在本应用里收验证码。

子账号权限更少。本应用只读车况和能耗，不远程控车。`deviceId` 不要清。换机或清数据后，刷新令牌会失效，需要重新短信登录。

## 安装 Debug APK

仓库带有 GitHub Actions：`.github/workflows/android-build.yml`。推送和拉取请求都会跑单元测试、打 Debug APK，并把 APK 上传成 artifact。

1. 打开这个仓库的 **Actions**。
2. 选中 **Android Build** 里最近一次成功的运行。
3. 在 Artifacts 里下载 `a10-energy-debug-apk`。
4. 解压后把 APK 装到手机上。Android 8 及以上即可。需要允许安装未知来源应用。

本地构建：

```bash
./gradlew testDebugUnitTest assembleDebug
```

APK 在 `app/build/outputs/apk/debug/`。需要 Android SDK 35 和 Build-Tools 35.0.0。

## 第一次在 A10 上核对

登录子账号后打开 **设置与诊断 → A10 原始信号诊断**，按顺序点：

1. **车辆列表**：确认有这台车，记下实际 `carType`（不要假设字符串一定是 `A10`）。
2. **getCarRoute**：看 `appRegion` 是不是零跑域名。诊断结果里的令牌已脱敏。
3. **车况 signalMap**：这一步只拉原始车况，不开始行程。核对有没有 `100003` 或 `1204`、`1318`、`1010`、`1149`、`1182`、`1349`、`sts`。页面顶部会标出有或无。
4. **今日官方能耗**：看是不是 `driverEC` / `acEC` / `otherEC`。今天如果返回 `code=100`，多半是云端还没记账，不要当成 0 度电。

如果数字号都没有、只有具名字段，把脱敏 JSON 留档。应用会尝试 `soc`、`totalMileage` 这类别名，但那只是兜底，不等于已经验证。

车况页可以打开后台自动记录。行驶中通知栏会保持前台服务。停车大约一分钟且不再移动后，这段行程会出现在行程列表。红灯这种短暂停不会把行程切碎。

## 可用容量

默认 50.0 kWh。设置里可以直接改，也可以打开「用一次充电反推」：

可用容量 ≈ 实充 kWh ÷ (充入 SOC% ÷ 100)

已经保存的行程只存 ΔSOC 和里程，电量按当前容量现算。改容量后，列表和统计会跟着变。

## 口径

- 新帧只看车端 `sts`，不看 `collectTime`。
- 耗电 = ΔSOC / 100 × 可用容量。
- 自动短途小于 0.2 km 不保存。百公里电耗在里程小于 0.5 km 或电量为负时留空。
- 官方分项不含驻车待机，本地分段是整段 SOC 差，两者不会相同。统计页把两边放在一起，就是为了看这个差别，尤其是暖风。

## 技术栈

Kotlin、Jetpack Compose Material 3、Room、Coroutines/Flow、OkHttp、kotlinx.serialization、EncryptedSharedPreferences、DataStore、前台服务。

## 声明

与零跑汽车无关。接口随时可能失效或加强风控。只在车主本人授权的车上使用，并且只用共享子账号。命中风控提示后请等待，不要反复点登录或刷新。
